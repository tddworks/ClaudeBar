Claude Code: take me to that terminal

Click a session in the Claude Code card, or press its number (1–9, 0 for the tenth), and its terminal comes to the front on the tab that runs it. ⌘1–⌘9 still pick providers. Try it: click a row or press a number while this page has focus. Design: docs/features/activity/session-hooks/design.md → Bring a session forward.

  • The small number before each row is its key. Rows behind +N more, and sessions that haven't yet said where they run, get no number and don't react to a click (dimmed here).
  • A folded Done row (claudebar ×3) brings forward the one that finished last.
  • tmux: the pane is selected first, then iTerm2's tab. Ghostty: the terminal open in the session's folder. Terminal, Warp and WezTerm: the app comes forward. Any other terminal: not clickable.
  • The notch's open panel does the same on click, with no number keys.
