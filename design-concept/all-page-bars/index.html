Every quota as a bar,one provider per row

Today the All page answers one question: which provider can I keep working with? — a ring for the quota that runs out first, two rows of small text beside it. It shows at most two quotas per provider, and its rings compare different windows side by side: a session on one card against a weekly on another.

This adds the second question people actually ask: how much room do I have on each window, lined up? Same page, same pills, same counts — chosen in Settings → General → All Page Style. Rings stay the default.

  1. One row per provider, in pill order — never re-sorted as quotas change. Same law the cards already keep.
  2. The account, when there are several. The bars read one login, the same one the ring reads today, named in the header.
  3. One line per quota the person watches — hidden quotas stay hidden, exactly as on the provider's own page.
  4. Fixed label column, fixed number column, bar fills the rest. That is what makes two providers' bars comparable; a bar that sizes itself to its label breaks the comparison.
  5. The percentage in the display mode already chosen (remaining / used / pace), with the pace tick where the page draws it today.
  6. The reset countdown under the label, so the tight line's number and its deadline sit together.
  7. The status colour is the fill's colour, and the badge stays the word for the whole provider.
  8. A tap still opens that provider's page. Nothing about the ring page changes; this is the same card, printed wider.

The awkward cases, drawn

One provider, several accounts

The bars read the login the ring reads today — the healthiest one, then the one with the most left — and the header names it. Nothing new to learn.

No numbers yet

A balance or a not-signed-in provider keeps its row and its word (Not set up, Syncing, Unavailable), as on the ring page. A provider never disappears because it has nothing to draw.

A balance instead of a percentage

A prepaid balance has no ceiling, so it gets no bar and a false 100% — the same rule the menu bar and the provider page already keep. The line still appears, with the amount.

Themes draw their own bar

The bar is the page's existing one: blocks under Platformer, a capsule under Outlined. Bars mode adds no drawing code of its own — it asks for a different width.

A long lineup

More rows means more scrolling in the same scroll region, capped as it is today. That's the one real cost of this mode, and it is why rings stay the default.

Hidden quotas

Quotas hidden in Settings → Providers stay hidden here. The bars show what the person watches, no more — which is what makes “every quota” safe to offer.
