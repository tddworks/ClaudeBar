THE DESIGN CHANGE

The theme gets one new optional property. Its default is nil, so no other theme changes and no view checks which theme is active.

// AppThemeProvider
var runner: GroundRunner? { get }   // default: nil

// GroundRunner, a value the theme returns
func pace(for status: QuotaStatus) -> RunnerPace
//   .stroll · .walk · .run · .fall
var sprite: PixelSprite              // frames, in art pixels
var lane: RunnerLane                 // .ownLane(48) or .behindControls

Platformer returns a runner; every other theme keeps nil. The StatusColorOverridingTheme wrapper forwards it like every other property.

LAWS AND OWNERS

LAWOWNER
Which status the runner showsThe selected provider's status, from QuotaMonitor. Unchanged, the same one the menu bar icon shows
How it moves for a statusThe theme: runner.pace(for:), beside statusWord(for:)
When it jumpsA refresh finishing: the same signal the ? block already watches. No new event in the Monitor
No frames while closedThe view: a paused TimelineView while the popover is closed
Stand still with Reduce motionThe view, from the system accessibility setting

STAYS OUT

  • Input of any kind: no keys, no clicks, no score. The floor stays non-interactive (allowsHitTesting(false)), like the current scenery.
  • Sound, and any runner in the menu bar itself. It only appears in the popover.
  • Any Nintendo character, name, sprite or sound. The runner is original pixel art, like the ? block and coin.
  • Settings: it comes with the theme. If people ask to turn it off, add a "Runner" toggle next to the Pixel / Classic text style.

For you to decide: where it walks. In its own lane, the runner is always visible, but the popover is 48 pt taller. Behind the buttons, the height stays the same, but the runner is only visible in the gaps between buttons, and the coin can be hidden.
