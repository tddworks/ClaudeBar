    What's uploaded
    One row per user, provider and day: input, output, cache-write and cache-read tokens. Computed locally from the same logs that drive Daily usage. Nothing else leaves the Mac.
    
  
    Which providers
    Only providers with local token logs can be ranked: Claude today, plus Codex and Mistral. Quota-only providers (Gemini, Copilot, Cursor…) report percentages, not tokens, so they're greyed out.
    
  
    Open questions
    • Backend and hosting: a small API plus a static page on GitHub Pages?
    • Anti-cheat: totals are self-reported. A per-install key signs uploads, and outliers get flagged.
    • Rank by total tokens, or output only, or cost?
