Themes

It should look like it belongs on your Mac.

Light and Dark ship built in. System follows your macOS appearance. CLI matches your terminal. Christmas turns itself on for the holidays.

Already tuned your terminal? Import any .itermcolors file and ClaudeBar wears it too.

What it does

Small app. Very few surprises.

Everything here exists to answer one question faster: can I keep going?

Live quota tracking

Session, weekly and per-model windows, refreshed on an interval you choose — plus cost, tokens and working time where the provider reports them.

Reset countdowns

Timezone-aware, down to the second, with a colon that ticks on its own clock. You always know how long until the window turns over.

Notifications that matter

A system notification when a provider crosses into warning or critical — and when a window resets. Nothing else pings you.

Only what you use

Toggle any of the nineteen providers off in Settings. The tab strip and the menu bar shrink to match — no dead entries for tools you don't have.

Five themes, or yours

Light, Dark, System, CLI and Christmas ship built in. Import an .itermcolors file and ClaudeBar generates a theme from it.

Native and self-updating

SwiftUI throughout, no web view in sight. Sparkle picks up new releases in the background, so the app you have is the current one.

Everywhere shortcuts: ⌘D Dashboard ⌘R Refresh
