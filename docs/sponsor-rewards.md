# ClaudeBar PR Sponsor Rewards

ClaudeBar offers a small sponsorship reward to thank open-source contributors.

## Rewards

- $1 for each eligible merged pull request.
- Maximum of one rewarded PR per UTC calendar day.
- Maximum of 30 rewarded PRs per calendar month.
- The first eligible PR merged each day receives that day's reward.
- Rewards are reviewed and processed at the end of each month.

## Eligible Contributions

Eligible contributions may include bug fixes, features, tests, documentation, CI/CD, performance, accessibility, security, and code-quality improvements.

A pull request must:

1. Be merged into the project's default branch by a maintainer.
2. Provide meaningful value to the project.
3. Pass the required CI checks.
4. Not be submitted by a project maintainer.
5. Not duplicate another pull request.
6. Not be reverted shortly after merging.

Merge times are determined using UTC. If multiple eligible pull requests are merged on the same UTC calendar day, only the first one receives that day's reward.

## Not Eligible

Automated dependency updates, formatting-only changes with no meaningful improvement, duplicate or low-value submissions, reward-driven split submissions, spam, malicious submissions, and pull requests merged after the monthly limit are generally not eligible.

The project maintainers make the final eligibility decision based on the quality and value of the contribution.

## Reward Processing

Rewards may be sent through GitHub Sponsors or another mutually agreed payment method. Contributors may instead donate the reward back to ClaudeBar, donate it to an agreed charity, or decline it.

Do not share sensitive personal information in public issues or pull requests.

## Reward Tracking

Eligible pull requests may use the labels `sponsor-reward`, `sponsor-reward-pending`, `sponsor-reward-paid`, and `sponsor-reward-ineligible`.

Public records may include the UTC date, pull request number, GitHub username, and reward status. Payment details will not be published.

## Important Notes

This is a voluntary thank-you, not an employment relationship, contract, or guarantee of payment. The program may be modified, paused, or discontinued at any time; changes will be documented here.

Thank you for helping make ClaudeBar better!
